# JAVA_AI_TRAIN

A comprehensive repository for Java Training, covering Core Java, JDBC, Hibernate ORM, Entity Mappings, and real-world hands-on projects.

---

## 📂 Repository Structure

| Module / Project | Description |
| :--- | :--- |
| **`JAVA_AI/`** | Core Java fundamentals, Object-Oriented Programming (OOP) concepts, collections, and exercises. |
| **`JAVA_AI_JDBC/`** | Java Database Connectivity (JDBC) examples, CRUD operations, and database drivers. |
| **`Hibernate/`** | Hibernate ORM framework configuration, sessions, transactions, and persistence. |
| **`Mapping/`** | Entity relationship mappings and JPA/Hibernate annotations. |
| **`ONEtoMANY/`** | One-to-Many relationship implementation examples. |
| **`ManyToOne/`** | Many-to-One relationship implementation examples. |
| **`MANYtoMANY/`** | Many-to-Many relationship implementation examples. |
| **`Library MS/`** | Library Management System project. |
| **`Projects/`** | Standalone console & utility projects (e.g., Contact Book Application). |

---

## 🛠️ Prerequisites

- **Java Development Kit (JDK 8 / 11 / 17+)**
- **Apache Maven** (for Maven-based modules)
- **Eclipse IDE** / **IntelliJ IDEA** / **VS Code**
- **Relational Database** (MySQL / PostgreSQL / Oracle as required by JDBC/Hibernate configs)

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/CommitWithSandy/JAVA_AI_TRAIN.git
   cd JAVA_AI_TRAIN
   ```

2. **Open in IDE:**
   - In **Eclipse**: `File` -> `Open Projects from File System...` -> Select `JAVA_AI_TRAIN` or individual module folders.
   - In **IntelliJ IDEA**: `File` -> `Open` -> Select the workspace or individual `pom.xml`.

3. **Build Maven modules:**
   ```bash
   mvn clean install
   ```
